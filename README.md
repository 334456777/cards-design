# 落差扑克牌占卜 · cards-web

一套**非线性、叠加态**的扑克牌占卜科普网站。不问吉凶,只问"此刻偏向哪一面"——每张牌由花色与数字两重含义叠合,而每一重都同时成立着自己与自己的相反:**优势即劣势,劣势即优势,随语境翻转。**

纯静态站点(原生 HTML / CSS / JS,无构建步骤),视觉取 Claude 官网那种**手绘暖调 + 复古书卷质感 + 烫金点缀**,信息密度向维基百科看齐。桌面与移动端均已适配,全中文界面。

## 架构:一个模板引擎 + 一个数据文件

54 张单卡页**不各存一份**,而是共用一个引擎:

- **`单卡页模板.html`** —— 引擎。读 URL 参数 `?c=<key>` 选牌并渲染,样式只此一处。
  例:`单卡页模板.html?c=spades_K`、`单卡页模板.html?c=joker_red`。
- **`cards-data.js`** —— 全牌库数据。含义按体系本质拆分:**花色面**(只与花色有关)× **数字面**(只与点数有关)共享维护;而**每张牌的导语、合成、正/反义例子在 `OVERRIDES` 里一牌一写**。
- **`cards_svg/`** —— 54 张牌面图(Vector Cards 3.2),命名 `<花色>_<点数>.svg`,如 `hearts_3.svg`、`spades_K.svg`、`joker_red.svg`。牌面图由 `key` 自动取用,无需手改。

`key` 形如 `hearts_3` / `spades_K` / `joker_red`,花色为 `hearts` `spades` `clubs` `diamonds`,点数为 `A 2…10 J Q K`。

### 改东西在哪改

- **改样式** → 只动 `单卡页模板.html`,54 张全站生效。
- **改某张牌的文字** → 只动 `cards-data.js` 的 `OVERRIDES`(按 `key` 补字段)。
- **换牌面图** → 替换 `cards_svg/<key>.svg`,路径不变。

## 设计系统

| 角色 | 取值 | 用途 |
|---|---|---|
| 纸底 | `#FAF6EF` / `#F4EDE0` | 背景,叠极淡纸张颗粒纹理 |
| 墨色 | `#2B2722` | 正文,暖近黑;黑色花色 ♠♣ |
| 烫金 | `#B8893A` / `#C9A227` | 花色符号、分隔线、首字下沉、链接 |
| 珊瑚 | `#D97757` | 交互高亮 / 选中态,克制使用 |
| 复古红 | `#A3372B` | 红色花色 ♥♦ |

- **标题 + 教程正文**:衬线 Noto Serif SC(英文 Spectral)。
- **导航 / 牌库 / UI**:无衬线 Noto Sans SC(英文 Inter)。
- 字体经 Google Fonts CDN 加载;手绘墨线、毛边卡框、波浪分隔线均用内联 SVG 滤镜实现。
- **签名交互**:单卡页/花色页的「正义 / 反义」叠加态开关——拨动后同一份特质在显义与隐义间翻面,直观体现"优势即劣势"。状态用 `localStorage` 记住。

## 本地预览

纯静态,任意静态服务器即可(直接双击打开也行,但用本地服务器能正确处理相对路径):

```bash
cd cards-web
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 部署(GitHub Pages)

仓库 Settings → Pages → Source 选 `main` 分支根目录即可。`index.html` 为入口。中文文件名会自动 URL 编码,链接照常工作。
